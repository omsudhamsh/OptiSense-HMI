# OptiSense HMI

AI-Powered Industrial Alarm Intelligence Platform

## Problem

Industrial operators face alarm floods and struggle to identify critical alerts in real time.

## Solution

OptiSense HMI uses AI and ISA-18.2 principles to prioritize alarms, reduce alarm fatigue, and improve industrial decision-making.

## Features

* Real-time industrial alarm dashboard
* AI alarm prioritization
* ISA-18.2 Alarm Health Score
* Operator and Engineer views
* Shift handover reports
* Equipment dependency graph

## Tech Stack

Frontend:

* React.js
* Tailwind CSS
* Recharts
* React Flow

Backend:

* Flask
* Flask-SocketIO
* pandas
* asyncua (OPC-UA)

AI:

* Gemini Flash-Lite API
